# 🐞 ¿Cómo puedo debugear?

Para que tengas total control y puedas debugear tus integraciones de manera efectiva, TusFacturasAPP te ofrece acceso a tus registros detallados directamente desde nuestra plataforma web:

{% stepper %}
{% step %}
### Consultar los hooks

Para consultar los hooks que te enviamos, podés ingresar tu "external reference" en Menú > Mi espacio de trabajo > API Request > Log de hooks dentro de nuestra plataforma.
{% endstep %}

{% step %}
### Descargar los requests enviados

Para descargar un registro de los requests que enviaste, podés acceder a Menú > Mi espacio de trabajo > API Request > Log de request API dentro de nuestra plataforma. Podras recuperar los logs de los últimos 3 días.
{% endstep %}

{% step %}
### Reporte de IVA ventas-compras

Para obtener un detalle completo de tus ventas, incluyendo la referencia externa que te permitirá relacionarlas con tu software, puedes acceder a un archivo Excel desde la plataforma. Dirígete a Menú > Reportes > IVA compras-ventas
{% endstep %}
{% endstepper %}

Estas herramientas te permitirán revisar la información enviada y recibida, identificando rápidamente cualquier posible inconveniente.
