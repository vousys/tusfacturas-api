# 🐞 ¿Cómo puedo debugear?

Para que tengas total control y puedas debugear tus integraciones de manera efectiva, TusFacturasAPP te ofrece acceso a registros detallados. Podés **consultar el log de hooks** y **descargar los requests enviados del día** directamente desde nuestra plataforma web, navegando a:

* **Menú > Mi espacio de trabajo > API Request > Log de hooks**
* **Menú > Mi espacio de trabajo > API Request > Log de request API**

Estas herramientas te permitirán revisar la información enviada y recibida, identificando rápidamente cualquier posible inconveniente.
